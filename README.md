# ⚡ Spectra FPS Meter

A modern, highly customizable floating FPS and hardware overlay for Windows.

![Version](https://img.shields.io/badge/version-1.2.0-blue.svg)
![Platform](https://img.shields.io/badge/platform-Windows-lightgrey.svg)

## ✨ Features
- **Real-time Metrics:** FPS, Frametime, 1% Low, 0.1% Low.
- **Hardware Sensors:** CPU/GPU temperatures, usage, and **Game-specific RAM usage** (unique feature!).
- **Fully Customizable:** Change colors, gradients, themes, and scale.
- **Multi-Language:** English, Portuguese, Spanish, and Chinese.
- **Lightweight:** Runs smoothly on a secondary monitor without interfering with your game.

## ⚙️ How to use
1. Download the installer (`SpectraFpsMeter_Setup_vX.X.X.exe`).
2. Run the installer and follow the on-screen instructions.
3. **Note:** The app requires Administrator privileges to read hardware sensors and capture FPS accurately.
